# 笔记 App（安卓版）

会议实时翻译笔记：对方说的日语 / 英语，按句编号翻译成中文。

## 安装

在手机浏览器打开：
https://github.com/BlooSim/notes/releases/download/app-latest/notes.apk

下载后点开安装（第一次需要允许浏览器「安装未知应用」）。之后每次更新，直接覆盖安装，笔记和设置都会保留。

## 功能

- **连续翻译**：点 ✎ 开始。大模型模式下，按停顿切成一段一段，交给 Gemini → Groq → Mistral 识别；某个额度用完自动换下一个，全都用不了时用手机识别。
- **按住说话**：按住期间对方说的整段话变成一条翻译。
- **悬浮窗**：像歌词一样浮在其他应用上面，可以拖动，点顶部一行可以折叠；悬浮窗上也能按住说话。
- **后台继续**：以前台服务运行，锁屏或切到其他应用也会继续听写，通知栏可以暂停 / 退出。
- 录音本身不抢音频焦点，其他应用的视频和音乐不会因此暂停。

## 构建

推送到 `android/` 目录后，GitHub Actions 会自动编译，并把 APK 发布到 `app-latest` 这个 Release。
签名使用仓库里固定的 `notes-signing.keystore`，保证每次构建都能覆盖安装。
